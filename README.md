# PSUSphere
## Description
PSUSphere is a Django-based student organization management system designed to manage colleges, academic programs, student organizations, students, and organization memberships. The project provides an organized way to store and manage student organization information through the Django administration site.

## Features
- Manage colleges
- Manage academic programs under different colleges
- Manage student organizations
- Manage student information
- Manage organization memberships
- Search and filter records in the Django Admin interface
- Generate initial data using the Faker package
- User authentication through the Django Admin superuser account
